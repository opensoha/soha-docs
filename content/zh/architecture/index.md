# 架构入口

各代码仓库的工程执行规则位于各自仓库的 `.agents/skills/`；跨仓库所有权和依赖规则
位于 OpenSoha 工作区根 `AGENTS.md`。

本目录只保留面向领域和专题的公共架构文档，不再重复维护以下工程记忆内容：

- 系统分层总览
- 前端工程结构总览
- 后端工程结构总览
- 工程变更规则与记忆更新规则

## 当前文档边界

这里保留：

- 主数据目录
- 应用交付
- 应用交付 DevOps 工作台
- 监控与告警
- AI Copilot
- soha AI Gateway
- 登录与身份链路
- Agent 协议
- 权限模型
- 多集群模型
- 事件模型
- 审计模型
- MCP 集成

工程实施时，以受影响仓库的 skill 为执行规则；公共专题设计与领域约束以本目录下
对应文档为准。

补充约定：

- 平台环境目录只维护可复用的集群、命名空间和阶段库存；应用环境绑定只在应用详情维护，并保存该应用的目标与发布策略。
- 兼容期内，部分权限键、scope 字段和后端存量数据仍沿用 `delivery.*`、`businessLineId` 与 `delivery_environments` 命名，但它们已经不再代表独立的用户可维护主数据入口。
